# 空间目标自主观测规划

面向第四题「面向空间目标持续监测的 AI 自主观测任务规划与目标状态分析」。

当前仓库包含三个可独立运行和对比的初版方案：

- **[方案E初版](方案E初版/README.md)**：既有调度基线与相关实验成果。
- **[方案G初版](方案G初版/README.md)**：AI候选评分、安全筛选、CP-SAT全局优化、候选回流与局部搜索。
- **[方案H初版](方案H初版/README.md)**：拉格朗日价格协调新算法，以及按统一规则口径（2026-08-01 至 08-07 UTC 规划期，含目标受照、48 小时重复观测）在全量上统一对比 A–H 的平台。

各方案的安装、测试和运行命令均从对应目录执行。三个方案应遵守同一份 **[规则口径](规则口径.md)**（以答疑文档及企业老师群内确认为准，规划期为 2026-08-01 至 08-07 UTC，列出待确认项）。

团队新的统一求解/自动评测接口位于 **[方案H初版/自动评测与协作](方案H初版/docs/自动评测与协作.md)**，队友 AI 从 [方案H初版/AGENTS.md](方案H初版/AGENTS.md) 开始阅读。评测从头生成 E/G+/H+ 来源，统一规则、独立校验和时间计分，支持其他算法通过 `module:function` 接入；这些 E/G 来源是 H 目录内的统一规则实现，不直接拿旧目录的不同日期结果混排。

最新选型依据见 **[时间加权优化实测报告](方案H初版/results/time-aware-2026-10-24/README.md)**：按已公布的计算结果/算法效率 4:3 占比设置内部比较权重，保留原始质量、完整耗时、独立校验与机器可读摘要。秒数换分公式未公布，因此报告不等于官方成绩。

- [从题目分析到完整解决方式](方案E初版/docs/方案E完整说明.md)：业务、规则、建模、几何、贪心、ALNS、CP 诊断、伐谋作用和后续工作。
- [实验结果汇总](方案E初版/results/README.md)：全量与拥塞场景的覆盖、观测权重分和验证范围。
- [本次发布验证](方案E初版/docs/发布验证.md)：独立安装、测试及真实场景复现记录。
- [伐谋接入与离线候选](方案E初版/integrations/famou/README.md)：本地复评与云端演化分别配置。

方案 E 的早期实验在其当时的开发假设下覆盖全部目标，观测权重分为 30,057.6；其伐谋候选在两个拥塞开发场景有改善。这些是历史结果，不能与最新 H 目录统一日期和几何口径后的结果直接混排，也不能视为比赛百分制成绩或等预算的 AI 优势。

各方案的产品与动态能力以对应 README 为准；新评测装置评估规划质量、效率与合法性，不代替产品体验评分。凭证、虚拟环境、完整计划与大缓存不提交；当前私有仓库已有两个小型赛题数据包，其他输入按对应目录 README 配置。
