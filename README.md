# 空间目标自主观测规划

面向企业赛题第四题「面向空间目标持续监测的 AI 自主观测任务规划与目标状态分析」的代码仓库。

项目目标是在有限地面观测资源下，为空间目标生成满足约束的观测计划，并根据任务和资源状态变化进行动态重规划。

## 当前状态

已初始化仓库，尚未实现调度算法或接入正式赛事数据。输入格式、物理约束和评分指标以主办方最终发布的规则为准；开发中的假设与合成数据应明确标记。

## 计划实现的流程

任务数据读取 → 观测机会分析 → 优先级判断 → 任务规划 → 约束校验 → 状态更新 → 动态重规划 → 结构化结果输出。

先建立可运行的基线和独立约束校验，再逐步接入已有调度方法、改进算法并开展对比实验。

## 目录

```text
src/        程序源码
tests/      正确性与场景测试
docs/       需求、设计与实验说明
data/       本地数据，默认不提交
outputs/    运行结果与生成文件，默认不提交
```

当前没有可执行入口。后续在实现程序时补充安装依赖、启动命令与示例。

## 协作约定

- 主要开发语言暂定为 Python，具体依赖随实现需要引入。
- 新功能使用独立分支开发，提交中说明变更及实际完成的验证。
- 原始赛题、未公开论文、报名材料、凭据和大体积数据不随代码提交。
- 合成场景的结果与正式赛事数据上的结果分别记录；不把演示运行当作正式验收。
