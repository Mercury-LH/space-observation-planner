# 观测规划首页

基于用户 2026-11-14 手绘草图与选定观测站背景的独立 React/Vite 前端。只修改本目录，不修改既有算法或 Streamlit 工作台。

## 本地预览

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

页面地址：`http://127.0.0.1:4173/`。既有工作台地址：`http://127.0.0.1:8501/`。

## 当前功能和边界

- 三个入口从页面右侧展开工作区。桌面可拖动左边缘调整宽度，键盘聚焦分隔线后可用左右方向键调宽。手机使用全屏布局。
- 配置与调整：设置开始日期、1–7 天时长、站点，保存到当前页面状态，可下载 JSON 配置。刷新恢复默认值。
- 运行观测规划：读取以上保存的配置，显示运行确认，并提供既有工作台入口。当前尚未向工作台传参或启动后端计算。
- 查看与导出：读取已有小规模示例，展示前 6 项任务与该示例的真实独立校验状态，下载完整 239 行 CSV 和摘要 JSON。不表示本轮重新运行或验证后端。
- 顶部导航仅保留“下载模板”和“上传数据”，透明无底；悬停或键盘聚焦时，文字向上移出并切换为相应的下载或上传图标，移除工具入口及工具栏。模板下载使用既有 TXT 字段格式；上传入口只在浏览器读取和预览文本，不向服务器上传或导入规划器。
- 首页可见时银河流动、草地随风起伏，流星间歇出现。三个入口采用 Spacious74 的平面长方形卡片，单列竖排，常态为深蓝底、银白功能名称，保留银蓝光束与装饰细线，去掉绕行光点。卡片采用 Apple 风格的连续圆角，本次网页适配选用约为卡片高度 22% 的圆角半径，并非 Apple 官方固定比例。悬停或键盘聚焦时，冰蓝色从左向右铺满卡面并显示启动、齿轮或放大镜图标，卡面及点击范围保持稳定，功能名称保持可访问。鼠标移走后快速退回深蓝常态，快速切换卡片时不残留浅色，键盘焦点仍保持清晰可见。

## 视觉来源

背景动画采样用户选定的原图。银河沿星带连续流动，尘带与星点局部提亮。前景草丛分区域随风摆动，观测站、镜筒和主要岩石保持原图姿态。默认使用 WebGL，设备不支持时使用 Canvas 2D。窄屏通过同一张真实背景图的两层取景和遮罩融合，让建筑位于按钮下方。没有用绘制图形替代观测站或星空。

品牌标志采用 Novaxlo 的动态地球，海面与陆地保留原作的蓝绿配色。其余界面图标来自 [Phosphor](https://github.com/phosphor-icons/react)，字体使用 [Noto Sans](https://notofonts.github.io/noto-docs/website/use/) 的简体中文版本，并保留系统中文字体回退。首页三个入口使用本地[资源圆体字形子集](public/fonts/README.md)。

原始数据证据：`../outputs/ux-review-20261113/plan_20261113-083604-HR.csv` 和对应摘要。发布用摘要移除了本机 `data_dir` 路径。下载 CSV 内容与源文件一致。
