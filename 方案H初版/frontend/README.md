# 观测规划前端

React/Vite 前端原型，包含观测站首页和「运行观测规划」「配置与调整」「查看与导出」三个工作区。当前版本提供本地配置、数据预览和已有结果展示。

## 本地预览

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

打开 [本地预览](http://127.0.0.1:4173/)。运行页中的「进入规划安排」链接指向 [本机 Streamlit 工作台](http://127.0.0.1:8501/)，需要单独启动该服务。

## 页面与数据

- **首页**展示银河、射电望远镜和带移动光点的站点地图。三个胶囊入口沿银色弧线排列，悬停时放大，圆形标记呈白底蓝黑图案。点击后，胶囊移向左侧天空并收拢成对应轨道图标，工作区从右侧滑入。
- **配置与调整**设置 UTC 开始日期、1–7 天时长、10 个站点中的至少一个，以及 H 价格协调、E 进化权重贪心 + 局部搜索或 B 固定优先级贪心。保存后可前往运行或下载 JSON 配置。返回未改动的已保存配置时可继续使用这两个操作。
- **运行观测规划**显示保存的时间区间、时长、站点资料和算法。「修改参数」返回配置页。「进入规划安排」打开既有工作台，参数传递和后端计算尚待接入。
- **查看与导出**读取示例 `20261113-083604-HR`，以双站观测钟展示 239 项任务，提供站点统计、停机时段和该示例的独立校验状态。任务表每页 6 项，可浏览全部任务，并下载完整 CSV 与摘要 JSON。页面展示和下载使用同一组示例文件。
- **下载模板与上传数据**位于品牌右侧。文字与托盘图标同时显示，悬停时箭头移动。模板采用已有 TXT 字段格式。「上传数据」在浏览器中列出本地文件并预览第一个文本文件，单文件上限 10 MB。

配置保存在当前 React 会话中，刷新恢复默认值。运行页读取最近一次保存的配置，示例结果来自固定存档。文件预览尚未连接到规划器的数据导入流程。

## 动效与视觉

工作区使用午夜蓝底色 `#061422`，左侧渐变与观测站场景融合。配置页与运行页之间的标题和内容一起横向切换，关闭后焦点回到入口。桌面工作区可以拖宽，也支持聚焦分隔线后用左右方向键调整；手机使用全屏布局。

工作区操作按钮从蓝色过渡到冰白色，移入与移出均为 0.8 秒。颜色渐变在系统开启“减弱动态效果”时仍然保留。普通动画模式下，观测钟外圈与扫光每 13 秒旋转一周，UTC 标签和任务色段固定；开启“减弱动态效果”时，观测钟旋转与扫光暂停。

品牌标志采用 Novaxlo 的动态地球，图标来自 [Phosphor](https://github.com/phosphor-icons/react)。中文正文使用 Noto Sans SC 与系统字体回退，首页入口使用本地[资源圆体字形子集](public/fonts/README.md)。首页胶囊和工作区按钮分别改编自 Uiverse 的 fuzzy-bullfrog-72 与 moody-mule-8，作者和许可证注释保存在组件及样式中。

示例计划的原始来源为 `../outputs/ux-review-20261113/plan_20261113-083604-HR.csv` 及对应摘要。前端运行时读取 `public/samples/` 内的发布副本，发布用摘要已清理本机数据与缓存路径。

## 开发与验收

```sh
npm run build
npm run test:sites
```

生产构建输出到 `dist/client/`，并生成静态托管所需的 `dist/server/index.js` 和 `dist/.openai/hosting.json`。四项静态托管测试覆盖文件服务、页面回退及打包结果。

接手说明见 [二级页面开发交接](二级页面开发交接.md)，视觉约定见 [AGENTS.md](AGENTS.md)，历史验收记录见 [design-qa.md](design-qa.md)。`qa/` 截图与 `references/` 设计参考是本地审阅材料，已由 `.gitignore` 排除；仓库中的源码和 `public/` 资源用于重建前端。
