# 伐谋演化方案 H 的放置规则（8 月口径）

## 演化对象

H 的价格协调收敛后，要把"每颗目标各自想要的观测"恢复成一份可行计划：两遍贪心，第一遍按某个优先级从高到低放置候选（窗口 × 时长），第二遍按真实价值补空，之后做共用的局部搜索和按秒精修。第一遍的优先级原来是人工写的"价值 − 价格"（`lagrange.recover`），现在交给伐谋演化：

- 接口：`score(names, rows) -> (uncovered, covered)`，每个候选一行特征，返回两个优先级（目标未覆盖时 / 已覆盖时）；
- 特征（`obsplan/famou_h_eval.py` 的 `FEATURES`）：原有窗口特征，加上价格协调本身的信息——候选的最低价格成本、窗口的需求拥挤度，以及每颗目标在收敛价格下"子问题"的选择（是否选了这个窗口和时长、选了几次、净收益）；
- 安全：候选代码在 macOS 沙箱中运行（不能联网、读仓库、启动子进程），只决定顺序；放置与全部硬约束由本地引擎保证。云端只拿到 `init.py`、`prompt.md`、`config.yaml`，数据和评测不出本机；
- 运行时接入：`lagrange.solve(rule=...)`。价格迭代照旧，结束后用最好一次可行解对应的价格，按演化出的规则重新恢复一次，再做局部搜索——与评测的做法相同。已采纳的规则放在 `obsplan/evolved/`。

先手工验证了这个对象值得演化：只给"子问题推荐的窗口"加一个常数优先，全量 H 精修后就从 0.9664 到 0.9701（+0.39%），用时不变。这个手写规则只用来证明评测有效，不作为伐谋成果。

## 三次实验

| 实验 | 目录 | 评测场景 | 轮数 | 训练场景上最好 | 全量（精修后，相对人工规则） |
|---|---|---|---:|---:|---:|
| `exp-20261022073345-kdyllg` | `famou_h/` | 20% 目标 × 3 站，2 个 | 100 | +2.67%（留出 +2.64%） | +0.06%（未采纳） |
| `exp-20261022085111-2z0hwh` | `famou_h2/` | 全部目标 × 3–4 站，2 个 | 150 | +1.11%（留出 −1.2% / +0.4% / +0.6%） | −0.10%（未采纳） |
| `exp-20261022103120-brwnpe` | `famou_h3/` | 全量实例本身 | 150 | 见下 | 见下 |

前两次共 250 轮，实际消耗约 4.1 万资源点（每轮约 166 点；创建时按预估预扣，结束后退回）。

**教训**：评测场景决定演化方向。第一次的子场景比全量宽松，偏重覆盖的规则被高估（全量下覆盖几乎饱和，多覆盖几颗换不来多少分，反而挤掉得分）；第二次换成拥挤程度与全量一致的子场景，但只有 2 个、站点固定，规则贴合了那几个站。赛题只有一个固定实例，正式评分也只看它，所以第三次直接在全量实例上评测：价格固定为人工规则 H 跑 300 次迭代的结果，候选规则放置 → 快速局部搜索 → 按秒精修 → 综合指标，每个候选约 30 秒。评测与已有实测一致：初始程序 1.000，上面的手写规则 +0.39%，第一次实验的最好规则 +0.06%。

## 运行

```bash
uv run --extra famou python scripts/famou_ctl.py experiment create --config integrations/famou_h3/config.yaml --experiment-name 名称 -y --json
scripts/famou_run_worker.sh 实验ID integrations/famou_h3/evaluator.py 2     # 本地评测，断网自动重启，2 路并发
uv run --extra famou python scripts/famou_ctl.py experiment results 实验ID --top 10 --output outputs/famou/名称
uv run python scripts/famou_adopt_check.py 候选.py --cases full --full --baseline --tag 名称   # 采纳检查
uv run python -m obsplan validate results/plan_H_evolved_名称.csv                            # Skyfield 校验
```

采纳规则：全量综合指标（端到端重新跑 H，不用评测时固定的价格）比人工规则提升不小于 0.2%，全量计划 Skyfield 逐秒校验 0 违规；人工审阅候选代码后合入 `obsplan/evolved/`，文件头注明实验编号和复评结果。
