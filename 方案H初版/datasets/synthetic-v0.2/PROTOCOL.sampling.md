# synthetic-v0.2 采样协议草稿

本文件规定采样方法与验收条件，供正式生产前冻结。它不表示 600 个场景已经生成、校验或发布。执行方式、教师配置、完整校验和发布验收由本版本主协议另行固定；本文件不得被用于放宽原有物理约束。

## 规模与数据划分

共 **600 个独立轨道目录，每目录只生成 1 个场景**，不以同轨道的四种变体补足数量。轨道、站点组合、优先级均由新随机源生成。train / validation / test 为 **420 / 90 / 90**：

| 分组 | train | validation | test | 合计 |
|---|---:|---:|---:|---:|
| 截断正态主体 `nominal_gaussian` | 420 | 60 | 60 | 540 |
| 显式标注压力组 `stress` | 0 | 30 | 30 | 60 |

各压力类型在 validation、test 分别有 5 个目录。验证集用于开发判断，测试集用于方案冻结后的评估；不根据教师质量、模型收益或可见窗口结果挑选种子，不将测试目录转入训练集。600 个目录中每个目录都有新的轨道随机种子；场景控制量采用分层采样，所以这里的“独立目录”不等于“600 份未经分层的 IID 高斯向量”。

目录 ID 为 `v2-cat-000` 至 `v2-cat-599`，对应场景 ID 为 `<catalog_id>-v0`。轨道种子为 `202711070000 + catalog_index`，与 v0.1 的种子域不同。控制量设计种子为 `2027110700`。正式规划期均为 **2027 年的六天**，TLE 历元设在各自规划期中点（开始后 3 天），不把 v0.1 轨道外推到新年份。

## 正态分布的适用范围

“常见情况多、极端情况少”落实为以下**主体场景控制量的截断正态分布**，记作 `TN(均值, 标准差, [下界, 上界])`。均值和标准差指截断前的母正态参数，不能把它们写成截断后样本的实测均值与标准差。全部参数是设计假设，没有拟合真实卫星群体或真实站点需求。

| 控制量 | 主体分布 | 使用方法 |
|---|---|---|
| 目标数 | TN(7000, 3000, [1000, 16000]) | 四舍五入到整数，保存取整前 latent。 |
| 站点数 | TN(10, 2.5, [4, 16]) | 四舍五入到整数，保存取整前 latent。 |
| LEO 占比 | TN(0.70, 0.10, [0.40, 0.92]) | 作为每目标类别抽样概率。 |
| 其余高轨中 MEO 占比 | TN(0.65, 0.12, [0.25, 0.90]) | MEO 概率为 `(1-p_LEO)×该值`，GEO-like 占剩余概率。 |
| 高优先级占比 | TN(0.25, 0.10, [0.03, 0.55]) | 高优先级分值固定为 5。 |
| 其余目标中中优先级占比 | TN(0.40, 0.10, [0.15, 0.75]) | 中优先级概率为 `(1-p_high)×该值`，中/低分值仍为 3/2。 |
| LEO 高度分布的均值/km | TN(1000, 180, [650, 1450]) | 用于下面的族内高度分布。 |
| LEO 倾角分布的均值/° | TN(65, 20, [20, 105]) | 用于下面的族内倾角分布。 |

每个 split 的主体部分独立划分为等概率分位数层，每层抽取一个均匀分位数，再通过**截断正态逆 CDF**转换。每个控制量独立打乱其排列后配对。这样可以在有限目录数下覆盖中心与两端；不采用“先抽普通正态再把越界值裁到边界”的方法，以免在边界制造人为堆积。

季节、轨道类别和周期角度不强行改成正态：主体按月份均衡覆盖，train 每月 35 个目录，validation/test 每月各 5 个目录。起始日在该月可完整容纳六天区间的日期中均匀选择，时刻固定为 UTC 00:00。轨道类别按记录的三类概率抽样；升交点赤经、近地点幅角、平近点角分别在 0°–360° 均匀抽样。

整体目标高度分布是 LEO/MEO/GEO-like 的混合分布。加入压力组后的全部 600 场景也是混合设计，**不宣称总体服从单一正态分布**。目标数与站点数的比值、窗口数、拥挤度、覆盖和任务得分是派生量，也不要求正态。

## 族内轨道分布与物理边界

每个目标在其轨道族内独立采样以下截断正态参数。高度指平均半长轴减去 WGS72 的 6378.135 km，不是每个传播时刻的瞬时高度。

| 轨道族 | 平均半长轴高度/km | 偏心率 | 倾角/° | B* |
|---|---|---|---|---|
| LEO | TN(场景高度均值, 250, [550, 1800]) | TN(0.004, 0.003, [0.00005, 0.012]) | TN(场景倾角均值, 12, [0, 120]) | TN(1.2e-5, 0.8e-5, [1e-7, 5e-5]) |
| MEO | TN(17000, 4000, [8000, 26000]) | TN(0.025, 0.020, [0.0001, 0.08]) | TN(55, 20, [10, 100]) | 0 |
| GEO-like | TN(35786, 300, [34500, 37000]) | TN(0.005, 0.006, [0.00001, 0.025]) | TN(5, 5, [0, 25]) | 0 |

LEO 的最小平均高度和最大偏心率组合仍使平均要素近地点高于 450 km。生成器逐目标检查这一条件，失败时报错，不静默替换轨道。使用 WGS72 初始化 SGP4，再导出 TLE、检查校验和并回读；正式传播必须基于回读 TLE。历元处传播返回码和位置/速度有限性必须通过，整段几何和任务合法性仍由后续流水线独立复核。

GEO-like 表示合成的近同步高轨类别，不代表所有目标都是严格的地球静止卫星。轨道间碰撞、真实卫星编队结构、目标亮度、传感器探测阈值及天气不在本采样器中建模。

## 站点网络

从代码中固定的 **24 个虚构陆地区域锚点**选择站点。一般网络先从南、北半球各选一个锚点，再从其余锚点中不放回抽取，避免普通主体退化成单一半球网络。网络选择方式写入 `network_mode`，选中锚点写入 `station_anchor_ids`。

每个站点的经度、纬度扰动分别为 TN(0°, 0.02°, [−0.06°, 0.06°])，高度扰动为 TN(0 m, 20 m, [−60 m, 60 m])。锚点高度是设计假设，未由地形数据库校正；它们不对应已建观测设备，不证明真实站址的地形、气象、光污染或仪器适用性。压力组另有区域集中网络。

该设计增加站点组合和站点数差异，仍共享固定锚点池，不能据此声称对全球任意新站址的泛化已被验证。

## 60 个单列压力场景

压力参数用各自预先指定的分布采样，不参与主体正态 CDF 检验。未列出的控制量仍按主体参数独立采样；每个场景保留完整配置。压力条件有意组合多个因素，不能将结果解释成单因素因果效应。

| `stress_type` | 对主体设置的覆盖 |
|---|---|
| `high_load` | 目标数 TN(13500,1200,[11000,16000])；站数 TN(5,1,[4,7])。 |
| `low_load` | 目标数 TN(2000,600,[1000,3500])；站数 TN(14,1,[12,16])。 |
| `leo_polar` | LEO 比例 TN(0.96,0.015,[0.93,0.99])；LEO 倾角 TN(95°,7°,[75°,110°])。 |
| `high_orbit` | LEO 比例 TN(0.30,0.05,[0.20,0.40])；剩余中的 MEO 占比 TN(0.45,0.10,[0.20,0.70])。 |
| `high_priority` | 高优先级比例 TN(0.72,0.07,[0.60,0.90])。 |
| `regional_network` | 目标数 TN(9000,1500,[6000,12000])；站数 TN(6,1,[4,7])；站点只从 7 个亚洲锚点中抽取，规划月固定为 6 月。 |

每个类型 validation/test 各有 5 个新轨道目录；这个数量只能提供有限的压力测试证据，不能单凭每类五个目录保证该类场景的稳定泛化。

## 分布验收与身份固定

采样实现为 [`v2_sampling.py`](../../obsplan/training_data/v2_sampling.py)。正式 specs 完整写入生成清单，`sampling_report(specs)` 结果保存到顶层 `sampling_report`。报告与文件哈希都属于验收证据，不能只公布几张直方图。

1. 正式目录恰为 600 个，ID 与新轨道随机种子均唯一；split 恰为 420/90/90，主体 540、压力 60；每类压力在 validation/test 各 5 个。
2. 所有目标数与站点数必须为整数且在各自物理/规模边界内，记录的整数与 latent 四舍五入值一致；轨道族概率、优先级概率均为有限正数且和为 1；站点锚点不重复。
3. 对主体中每个 split、每个连续控制量，按约定截断正态 CDF 把 latent 转回分位数。要求每个等概率层恰有一个样本，记录分位数与回算值误差不超过 `1e-12`；经验 CDF 与目标截断正态 CDF 的最大偏差不超过 `1/n + 1e-12`，其中 n 为该 split 主体目录数。
4. 主体月份数量必须与上表完全一致；validation/test 的主体各至少 9 个目录达到 10,000 目标。按冻结种子，实际规格中两者均为 10 个；不根据生成后的模型表现调整种子。
5. 使用的是确定性分层设计，不报告普通 IID Kolmogorov–Smirnov 或 Shapiro 检验的 p 值，不以“p > 0.05”为通过标准。取整后的目标数/站点数是离散化截断正态；轨道族混合及压力组另行统计。
6. 单测覆盖配置篡改、重复种子、错误划分、分布层缺失、日期越界、概率错误、站点映射错误，以及原生文本/TLE 回读和六天代表性传播。单测通过不替代全部正式计划的独立逐秒校验。

当前规格的规范 JSON SHA-256（按键排序、紧凑分隔、UTF-8）为：

`52f2b3af32c95aa8769dfb24cb7691ae586db33008ea515c80c63a4cab04d4a3`

仅按上述规格计算，计划产生 **4,334,032 条独立合成轨道**，其中 train 3,004,421、validation 658,937、test 670,674；这不是已完成生成的实测数量。目标数规格实际范围为 1,076–15,935，站点数覆盖 4–16。规模分箱只用于分组报告：small 为少于 4,000 目标，medium 为 4,000–9,999，large 为至少 10,000，不能把分箱写成固定的 1,000/5,000/10,000 三个取值。
