# 方案 E 初版维护约定

本目录是独立可安装的 Python 项目快照，已实现静态调度和伐谋候选评测。父目录的早期骨架描述不代表本目录当前状态。

- 从本目录安装和执行：`python3 -m venv .venv`，`.venv/bin/python -m pip install -e '.[dev]'`，`.venv/bin/python -m pytest -q`。
- 数据加载、几何、调度、独立校验保持分离；学习或启发式评分不能代替硬约束检查。
- 更改算法时同时记录初解、随机种子、实际预算、分项指标和完整校验状态。物理近似、开发假设与正式规则分开写。
- 不提交 `data/` 下的原始数据、`outputs/`、密钥、虚拟环境、报名材料或未公开论文；仅提交合成测试和可分享的指标摘要。
- 新运行使用新的输出目录，不覆盖历史结果。历史文档中的 `outputs/...` 是原实验本地位置，不表示已经随 Git 发布。
- 云端实验与本地复评分开；仅在有授权时发起会消耗资源点的云端任务。
- 当前未完成动态闭环和界面，不将规划中的功能描述为已验证。
- 提交前运行适合变更的测试及 `git diff --check`，维护本目录 README 中的复现说明。
