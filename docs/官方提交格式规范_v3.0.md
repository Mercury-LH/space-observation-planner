# 学生拍摄方案 - 输入格式规范

## 1. 文件格式

- **格式**: JSON 文件（`.json`）
- **编码**: UTF-8
- **结构**: 数组（Array），每个元素为一个观测对象

## 2. 观测对象字段

```json
{
  "noradId": 28446,
  "siteCode": "site_1",
  "startTime": "2026-08-01T10:01:00Z",
  "endTime": "2026-08-01T10:04:30Z"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `noradId` | integer | ✅ | 卫星 NORAD 编号（5位数字） |
| `siteCode` | string | ✅ | 站点编码（见站点列表） |
| `startTime` | string | ✅ | 观测开始时间（UTC） |
| `endTime` | string | ✅ | 观测结束时间（UTC） |

## 4. 时间格式规范

- **格式**: ISO 8601 UTC 时间
- **示例**: `2026-08-01T10:01:00Z`
- **范围**: 2026-07-31T00:00:00Z ~ 2026-08-06T23:59:59Z（共7天）

## 5. 排序要求

- **按站点分组**：所有同一站点的观测应连续排列
- **每组按时间升序排序**：开始时间早的排在前面
- **示例**:
  ```
  site_1 的观测 → 按时间升序
  site_2 的观测 → 按时间升序
  ...
  site_10 的观测 → 按时间升序
  ```

## 7. 约束规则

### 7.1 调度约束
- 同一站点的相邻观测之间至少间隔 **30秒**
- 违反则判定为**硬错误**（不计分）

### 7.2 时长约束
- 单次观测有效拍摄时长需 **≥120秒**
- 超过 **240秒** 按满分计算
- 有效时长 = 学生方案与预报窗口的时间交集
- 时长不足判定为**硬错误**（不计分）

### 7.3 48小时冷却规则
- 同一卫星的相邻两次观测间隔需 **≥48小时**
- 48小时内的二次观测判定为**硬错误**（不计分）
- 规则：任意相邻两次间隔<48h，第二次起都不计分

### 7.4 时间偏差容错
- 学生方案时间与预报窗口偏差 **≤1秒**：正常计分
- 偏差在 **1~5秒** 之间：判定为**软错误**（计分×50%）
- 偏差超过5秒且无有效交集：判定为**硬错误**（不计分）

## 8. 评分规则

### 8.1 优先级分值
| 优先级 | 分值 |
|--------|------|
| 高 | 5 分 |
| 中 | 3 分 |
| 低 | 2 分 |

### 8.2 时长得分
```
有效时长          时长得分
─────────────────────────────
<120s            0.0 (硬错误)
120s             0.6
120~240s         0.6 + 线性插值
≥240s            1.0
```

### 8.3 最终得分计算
```
单条得分 = 优先级分 × 时长得分

软错误调整:
  - 硬错误 → 0 分
  - 软错误 → 单条得分 × 50%
  - 正常  → 单条得分

错误率 = max(0, 1 - (硬错误数 + 软错误数) / 覆盖卫星数)

最终得分 = 所有有效得分累加 × 错误率
```

## 9. 示例评分

### 场景：3条观测

| # | 卫星 | 站点 | 状态 | 有效时长 | 单条分 | 实得分 |
|---|------|------|------|---------|--------|--------|
| 1 | 28446(高) | site_1 | 正常 | 210s | 4.5 | 4.5 |
| 2 | 99999(未知) | site_2 | 硬错误 | - | 0 | 0 |
| 3 | 25544(中) | site_3 | 软错误 | 207s | 2.67 | 1.33 |

### 计算过程
```
基础得分 = 4.5 + 0 + 1.33 = 5.83
覆盖卫星 = 2 颗 (28446, 25544)
硬错误 = 1 (第2条)
软错误 = 1 (第3条)
错误数 = 2
错误率 = max(0, 1 - 2/2) = 0.0
最终得分 = 5.83 × 0.0 = 0.0
```
